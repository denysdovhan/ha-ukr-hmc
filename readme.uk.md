## Встановлення

Найпростіше встановити інтеграцію через [HACS][hacs-url]. Натисніть кнопку нижче:

[![Додати до HACS через My Home Assistant][hacs-install-image]][hacs-install-url]

<details>
  <summary>Якщо кнопка не працює, додайте репозиторій вручну</summary>

1. Відкрийте **HACS** → **Інтеграції** → **⋮** → **Користувацькі репозиторії**.
2. Натисніть **Додати**.
3. Вставте `https://github.com/denysdovhan/ha-ukr-hmc` як URL-адресу репозиторію.
4. Виберіть **Інтеграція** як категорію.
5. Знайдіть і встановіть **Український гідрометеорологічний центр**.

</details>

[![Додати Український гідрометеорологічний центр][install-image]][install-url]

<details>
  <summary>Якщо кнопка не працює, додайте інтеграцію вручну</summary>

2. Натисніть **Додати інтеграцію** та знайдіть **Український гідрометеорологічний центр**.
3. Виконайте кроки налаштування.

</details>

## Що надає інтеграція

![Створення сутностей](./media/create-entries.png)

Інтеграція дозволяє створювати такі сутності:

| Джерело                | Поточні дані                                                                            | Прогнози              |
| ---------------------- | --------------------------------------------------------------------------------------- | --------------------- |
| Метеорологічна станція | Вимірювання фізичної станції: температура, вологість, тиск, вітер і погодні умови       | Добовий і на день/ніч |
| Погода для місця       | Прогнозовані умови для точки на карті; вимірювання фізичних станцій не використовуються | Погодинний і добовий  |
| Радіологічна станція   | Безпосередні значення у мкР/год і нЗв/год та час спостереження                          | —                     |
| Гідрологічний пост     | Щоденні вимірювання води та гідрологічна ситуація від постачальника                     | —                     |

Інтеграція також створює п’ять глобальних бінарних сенсорів уваги постачальника. Вони показують увагу до метеорологічного, гідрологічного, снігового, радіаційного або пожежного продукту, але не є регіональними попередженнями й не містять рівня небезпеки чи строку дії.

Для погоди за місцем поточна сутність використовує запис постачальника за поточну годину. Добовий прогноз відповідає поданню meteo.gov.ua: запис на 03:00 надає мінімальну температуру, а запис на 15:00 — максимальну температуру та стан погоди. Неповні дні пропускаються.

Радіаційні вимірювання та гідрологічні ситуації відображаються так, як їх опублікував постачальник. Інтеграція не визначає рівень безпеки, не створює попереджень і не замінює офіційних рекомендацій.

### Погода

Ви можете стежити за погодними умовами за допомогою фізичної метеорологічної станції або вибравши місце на карті. Інтеграція надає і поточні погодні умови, і прогнози.

Види прогнозів відрізняються:

- **Метеорологічні станції** надають добові прогнози та прогнози на день/ніч. Дані оновлюються _кожні 3 години_.
- **Погода для місць** надає погодинні та добові прогнози. Дані оновлюються _щогодини_.

Погода для місця також надає поточні опади. Фізичні станції надають схід і захід сонця, діагностичні службові коди та компактний сенсор детального прогнозу. В його атрибутах зберігаються опубліковані діапазони температури для дня й ночі, текст опадів, хмарність і діапазони швидкості вітру.

#### Погодні сутності й сенсори

| Сутність | Метеостанція | Погода для місця | Пояснення |
| -------- | :----------: | :---------------: | --------- |
| Погода | ✅ | ✅ | Станція: поточні вимірювання та добові прогнози і прогнози на день/ніч. Місце: модельні умови на поточну годину, погодинний і добовий прогнози. |
| Погодні умови | ✅ | ✅ | Стандартний стан погоди Home Assistant. |
| Текст погоди | ✅ | ✅ | Опис, опублікований УкрГМЦ. |
| Температура | ✅ | ✅ | Поточне вимірювання станції або прогноз для точки на поточну годину. |
| Вологість | ✅ | ✅ | Відносна вологість. |
| Тиск | ✅ | — | Вимірювання фізичної станції у мм рт. ст. |
| Швидкість вітру | ✅ | ✅ | Поточна швидкість у м/с. |
| Напрямок вітру | ✅ | ✅ | Напрямок у градусах; для місця також доступне компасне значення постачальника. |
| Поточні опади | — | ✅ | Безпосереднє значення прогнозу для точки у мм. |
| Опади за наступні 1/3/6/12/24 години | — | ✅ | Сума повного набору погодинних значень опадів у відповідному проміжку. |
| Найближчі опади | — | ✅ | Час першої наступної години з опадами понад 0 мм. |
| Мінімум / максимум сьогодні та завтра | — | ✅ | Безпосередні нічні/мінімальні та денні/максимальні значення добового прогнозу постачальника. |
| Максимальний порив за 24 години та його час | — | ✅ | Найбільший опублікований погодинний порив та час його прогнозу. |
| Час даних | ✅ | ✅ | Час спостереження або прогнозу від постачальника. |
| Схід / захід сонця | ✅ | — | Сенсори часової позначки. |
| Код явища / індикатора | ✅ | — | Службові коди постачальника; типово вимкнені. |
| Детальний прогноз | ✅ | — | Діагностичні атрибути з денними й нічними діапазонами температури, текстом опадів, хмарністю, діапазонами вітру, сходом, заходом сонця та кодом постачальника. |

Погодинний прогноз доступний лише для налаштованої **погоди для місця**. Він надходить безпосередньо з точкового прогнозу УкрГМЦ `dataDetailed` і може містити температуру, погодні умови, опади, тиск, вологість, точку роси, швидкість і пориви вітру та напрямок — якщо постачальник опублікував відповідні значення. Home Assistant показує ці дані через сервіс прогнозу погодної сутності та картки з підтримкою прогнозу, а не як окремий сенсор для кожної години.

### Діагностика служби та глобальні прапорці

Спільний пристрій служби УкрГМЦ надає:

| Сутність | Значення |
| -------- | -------- |
| API доступний | Бінарний сенсор зв’язку. Увімкнений, якщо останнє планове оновлення даних завершилося успішно, і вимкнений після помилки оновлення. |
| Останнє успішне оновлення | Час отримання останнього повного набору даних; зберігається під час тимчасових помилок. |
| Дані застаріли | Сенсор проблеми, який активується, якщо останнє повне успішне оновлення було понад 45 хвилин тому. |
| Послідовні помилки оновлення | Кількість невдалих звернень до постачальника після останнього успішного оновлення. |
| Загальні метеорологічний, гідрологічний, сніговий, радіаційний і пожежний прапорці | Безпосередні глобальні прапорці постачальника. Це не регіональні попередження: вони не містять рівня небезпеки, тексту чи строку дії. |

Усі дані опитуються одним спільним координатором кожні 15 хвилин. Діагностичний час оновлення означає момент успішного отримання повного набору даних Home Assistant, а не час спостереження окремої станції. Підсумкові сенсори прогнозу потребують повного набору погодинних записів у вибраному проміжку: якщо значення опадів відсутнє, сенсор матиме невідомий стан, а не вважатиме пропуск нульовими опадами.

## Видалення

1. Відкрийте **Налаштування** → **Пристрої та служби**.
2. Виберіть **Український гідрометеорологічний центр**.
3. Відкрийте меню **⋮** і натисніть **Видалити**.
4. Видаліть інтеграцію з HACS і перезапустіть Home Assistant, якщо користувацький компонент більше не потрібен.
